# Outputs that are not one file

Not every output is a single file with a fixed name.

!!! note "Outline: to be written"

    - Optional outputs: `Path | None`
    - Values instead of files: `count: int`, declared with `output(count=3)`
    - A folder as output
    - Tools that write several files with a common prefix: `PathPrefix`, and `input.prefix.matches()`
    - File names only known at run time: `output(name=...)`
